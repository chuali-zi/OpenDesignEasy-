为什么选择 ForgeCLI

四个核心设计理念，覆盖从初始化到发布的每一个环节。

毫秒级启动

Rust 原生编译，无运行时依赖。冷启动小于 50ms，增量构建只处理变更模块，大型项目也能秒级完成。

插件化架构

通过声明式清单扩展任意命令。官方市场已有 300+ 插件，涵盖部署、数据库迁移、代码生成等场景。

零配置上手

智能识别项目类型，自动推断合理默认值。需要定制时，一份 forge.toml 即可覆盖所有行为。

三分钟完成安装

支持 macOS、Linux 与 Windows，也可从源码自行编译。

  • 1
    运行安装脚本 使用系统自带的包管理器或一键脚本，自动检测平台并下载对应二进制。
  • 2
    初始化第一个项目 forge init 会引导你选择模板与工具链，生成可直接运行的工程结构。
  • 3
    探索命令帮助 每个子命令都内置 --help 与示例，配合 forge docs 可在浏览器中打开本地文档。
# 使用一键脚本安装 $ curl -fsSL forge.dev/install.sh | sh # 或者通过包管理器 $ brew install forgecli $ cargo install forgecli # 验证安装 $ forge --version forgecli 3.2.1 (stable, 2024-05) # 创建并构建项目 $ forge init my-app --template web $ forge build --release
