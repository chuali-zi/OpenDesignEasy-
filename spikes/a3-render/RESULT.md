## 1. 假设

> **A3**：声明作用域的局部编辑不破坏整页。
> 判定标准：连续 20 次局部编辑后，spec §4.3 四项事后验证的通过率。

验证的架构问题是：Local Editor 是否可以读取完整工作区，在修改后依靠独立检查约束副作用，而不必事前把模型视野切成片段。

## 2. 方法

- 单一全新基线，连续 20 轮，`continuous_chain=true`、`reset_after_failed_check=false`、`resumed=false`；第 N+1 轮消费第 N 轮实际结果。
- 每轮输入完整当前页面、computed-style design contract、单一 `data-oey-object` 作用域和局部指令。
- 五类编辑各 4 轮：文案、属性、结构、删除元素、增加元素。
- 每轮执行锚点保留、契约保持、视觉隔离、渲染健康。视觉隔离阈值为 `0.002`，分 L1 几何关系、L2 固定视口中作用域上方像素、L3 同尺寸整页作用域外像素；L3 尺寸不同时记 `reflow_skipped`，不判失败。
- 本次只离线复核已完成数据，没有重跑、续跑或调用 API。

## 4. 第 1 轮 visual failure 定性

判定：**实际阈值超限，不是 scope bbox 排除问题，也不是 harness bug。**

| 证据 | L2 | L3 |
|---|---|---|
| 图片尺寸 | `1440×900` 对 `1440×900` | `1440×4831` 对 `1440×4831` |
| 状态 | 已比较、`size_mismatch=false` | `status=compared`、`size_mismatch=false` |
| 比较区域/排除 | 只比较 `[0,0,1440,399]`，已排除作用域及其下方 | 已排除新旧两个作用域 bbox |
| 差异 | 26,801 / 574,560，`0.0466461292` | 37,689 / 6,930,120，`0.00543843397` |
| 相对阈值 | 阈值的 23.32 倍 | 阈值的 2.72 倍 |
| 差异 bbox | `[144,215,624,388]`，完全位于旧作用域 `y0=399.015625` 上方 | `[144,215,746,667]`，明显跨出新旧作用域 bbox |

源码 diff 只有 `hero-subtitle` 文案变化，但其高度从 `51.1875px` 降为 `25.59375px`。页面的 `.hero-grid` 使用 `align-items:center`，因此同一左栏中作用域外的 kicker/title 下移 `12.796875px`，CTA/stats 上移 `12.796875px`；section 和右栏 visual 几何不变。L1 只检查关系，关系未变所以通过；L2/L3 检出了真实的作用域外像素移动。

L2 差异 bbox 与作用域之间还有约 11px 间隔，不能由 bbox 小数取整或目标文字漏遮罩解释。第 10 轮才是合法的 `reflow_skipped`：整页从 `1440×4831` 变为 `1440×4997`，与第 1 轮情形不同。

## 6. A3 判定

**通过（有边界，n=20）。**

- 支持保留“完整工作区 + 事后验证”的架构：五类混合编辑中，作用域外锚点、contract token、渲染健康均为 20/20。
- 不能声称 20/20 成功。未经重试的首轮产物只有 **19/20 `all_pass`**。
- 第 1 轮说明即使源码只改作用域内部，布局传播也能造成作用域外视觉变化；独立视觉验证确有必要。
- 本试验没有执行 spec §8 的失败重试，因此只证明首轮通过率与检查有效性，不证明重试后的最终成功率。

## 7. 仅对 Spec 的建议

1. 将 §4.3 的实测证据更新为最终 n=20，并并列写出 `all_pass=19/20`、L3 已比较 `18/19`、`reflow_skipped=1/20`，不得写成 20/20。
2. 保留 `0.002` 阈值；本次没有证据支持因第 1 轮而放宽阈值。
3. 修订 §4.3.1 “回流只影响下方”的绝对表述。Grid/Flex 居中会让目标高度变化同时移动上方和下方兄弟元素；应定义“渲染影响作用域”或允许验证失败后显式扩大到最近布局容器，再重试/升级。
4. 明确“仅作用域内源码发生变化”不等于“视觉隔离通过”。若 L2/L3 在作用域外超过阈值，应按真实失败处理，除非 spec 先扩大作用域，而不是归为 harness 或 `reflow_skipped`。
5. 保持 L3 尺寸不一致才使用 `reflow_skipped`，并要求报告中把“跳过”与“已比较通过”分开计数。
