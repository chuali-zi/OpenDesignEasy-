# Spike D4 / D5：Seedream 可控性与输出权利

> 执行日期：2026-07-28（UTC）。模型：`doubao-seedream-5-0-260128`。
> 结论仅覆盖本次实测与访问到的官方条款，不构成法律意见。

## 1. 结论

| 假设 | 结论 | 决策 |
|---|---|---|
| D4：Seedream 的尺寸/风格可控性满足配图需要 | **通过（限本次测试范围）** | 2 种尺寸、2 种明确风格共 4/4 成功；实际尺寸 4/4 与请求一致，风格指令产生可辨识差异 |
| D5：Seedream 输出的商用权利条款可确认 | **部分** | 官方权利来源可确认，但客户交付权不够明确；生成图继续标记 `RightsStatus.ANALYSIS_ONLY`，不得进入交付物 |

本次解除的是 D4 的凭据阻塞。D5 不再是“找不到权利来源”，但仍不足以标记
`CLEARED_FOR_DELIVERY`：需由法务结合账号实际订购协议/服务订单确认交付授权后才能放行。

## 2. 假设原文

- **D4**：Seedream 的尺寸/风格可控性满足配图需要。
- **D5**：Seedream 输出的商用权利条款可确认，结论明确到能填 `RightsStatus`。

## 3. 方法

### D4 API 探针

- 从仓库根 `.env` 以 `utf-8-sig` 读取 `ARK_API_KEY`、`ARK_BASE_URL`、`ARK_MODEL_ID`；报告、日志与原始记录均不含密钥。
- 直接调用配置的 `POST https://ark.cn-beijing.volces.com/api/v3/images/generations`。
- 固定主体、配色与构图，只改变尺寸和风格描述，形成 `2 x 2` 组合：
  `2048x2048` / `2560x1440`，`paper_cut` / `studio_photo`。
- 请求使用 `response_format=url`、`watermark=false`。下载原始响应图，记录脱敏响应元数据、实际尺寸、字节数、SHA-256 与延迟。
- 对 429、500、502、503、504 最多按 2 秒、4 秒有限重试；鉴权错误、网络错误和结构错误立即失败。
- 人工查看原图仅判断尺寸和风格指令是否可辨识，不评价审美优劣。

### D5 官方条款核验

- 使用 `rights_probe.py` 启动本机 Chrome 渲染官方动态页面。
- 启动前清空进程环境，仅恢复 Chrome 所需系统变量白名单；不读取 `.env`，不向浏览器进程传递 API 密钥。
- 保存最终 URL、页面标题、HTTP 状态、抓取时间及正文到 `raw/official-rights-pages.json` 和逐页文本文件。

## 5. D5 官方证据

访问时间：2026-07-28 UTC。三页均返回 HTTP 200。

| 官方页面 | 证据用途 |
|---|---|
| [Seedream 图片生成 API](https://docs.volcengine.com/docs/82379/1541523?lang=zh) | 明确本次 endpoint 是 Seedream 5.0/4.x 图片生成 API，并列出 `size`、`response_format`、`watermark` 等参数 |
| [生成式模型服务专用条款](https://docs.volcengine.com/docs/6561/1533787?lang=zh) | 定义、许可、生成内容知识产权及风险分配；页面最近更新时间为 2026-03-25 |
| [火山引擎服务条款](https://docs.volcengine.com/docs/6256/64903?lang=zh) | 通用服务条款；原请求 `/6256/64982` 被官方重定向至 `/6256/64903` |

专用条款中的关键事实：

- §1.1 说明条款适用于订购和使用“生成式模型服务”；§2.1 明确定义包含通过 API 提供的**图片**生成式模型产品和服务。因此虽页面位于豆包语音文档树，条款文字覆盖图片生成 API。
- §1.2 说明完整协议还包括通用服务条款、产品和服务协议、订购协议/服务订单及其他适用规则；公开页面不是完整合同集合。
- §3.3 的普通许可为非独占、不可转让或再许可、有期限、可撤销且仅限中国大陆；§3.3(3) 仅允许在完整使用生成内容时使用其中单独归属于火山引擎的内容。
- §3.5 允许客户在合法合规范围内自行维护和使用基于生成内容产生的知识产权，但未明示知识产权归属转让，也未明示可将生成图作为客户交付物转让或再许可。
- §3.5 同时说明输出可能不独特，其他用户可能获得类似内容；相关使用风险与纠纷由客户承担。
- §3.9 禁止侵权使用，并禁止删除、篡改或隐匿输出中的深度合成服务标识。

### RightsStatus 决策

公开官方条款足以证明“允许一定范围的生成内容使用”，但不足以证明本项目需要的“可商用并可进入客户交付物”：

1. 客户交付通常涉及向客户转移或许可使用，而公开许可明确不可转让、不可再许可。
2. 许可有地域、期限及可撤销限制，不能直接映射为无条件交付清权。
3. 完整协议依赖实际订购协议/服务订单；本 spike 未取得也不应推测其内容。

因此 D5 结论为**部分**，当前唯一可辩护的枚举值是
`RightsStatus.ANALYSIS_ONLY`。只有法务核对实际账号合同并书面确认目标地域、期限、客户交付和再许可范围后，
才可改为 `CLEARED_FOR_DELIVERY`。

## 6. 失败模式与边界

- 缺少任一 Ark 配置时探针以 `BLOCKED` 退出，不发请求。
- 401/403、网络失败、响应不是单个 `data[0].url`、下载失败或无法解析图片尺寸时停止，并将脱敏失败写入运行记录。
- 429/指定 5xx 仅有限重试，不会无限消耗额度。
- URL 返回值可能过期，探针已保存原图；`run.json` 删除了 `url` 与 `b64_json`，避免落盘临时下载凭证或大块内联数据。
- D4 只有四个样本，没有覆盖长文本、人物、品牌元素、参考图、多轮编辑、批量并发、复现性或安全审核。
- D5 只判断公开条款是否足以支撑系统枚举，不替代法律审查。

## 7. 对 Spec 的修订建议

不在本 spike 中直接修改规范，建议后续：

1. 将 §11 的 D4 更新为“通过（限 2048x2048、2560x1440 与两种明确风格，4/4）”。
2. 将 D5 更新为“部分：官方条款来源已确认，但客户交付授权不足；默认 `ANALYSIS_ONLY`”。
3. 在 §4.5 明确 `CLEARED_FOR_DELIVERY` 必须关联权利证据：条款 URL/版本、访问时间、订购协议或法务审批、适用地域、期限及是否允许客户交付/再许可。
4. 保留“条款未确认前为 `ANALYSIS_ONLY`”规则，并扩展为“公开条款存在但交付范围不明确时也为 `ANALYSIS_ONLY`”。
5. 生图 Adapter 保存请求模型 ID、prompt、请求/实际尺寸、内容哈希和权利证据版本；不得把临时外链直接用于交付代码。
