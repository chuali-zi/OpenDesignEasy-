# Web 原生组与流式组

2026-10-13，沿 WebDocument 统一命令/历史实现。连续兄弟的原生像素绝对定位对象可分组；组是带 `group: true` 的原生 div，成员仍为可编辑节点。创建时用真实 DOM 边界转换为组内局部坐标，并保留叠放顺序。组不能拥有独立文字或受管组件绑定。

选中组后在成员区域拖动会移动整个组；缩放手柄和宽高字段调整组及成员几何，一次手势一条命令。嵌套原生组递归调整成员位置/尺寸；普通容器内部继续按自身布局排版，不强行缩放字体。考虑真实 margin，预演与提交使用相同快照；Escape/pointercancel恢复所有临时样式，不增加历史。

解组将成员转换回父级坐标并恢复兄弟顺序。旋转/变换或组外观/附加属性不能无损摊平时明确拒绝；先恢复原生无装饰组再解组。锁定对象、祖先和后代整批保护；内核也拒绝通过直接组样式命令绕过锁定后代。测量依赖含对象/祖先几何、源码/断点及组成员列表，提交前改变时拒绝旧测量；无关名称变化可合并。

支持边界：同父级连续兄弟、绝对定位、明确像素坐标/尺寸、无外部CSS或几何响应式覆盖。分组/解组/组几何手势与宽高字段只在基础视口执行；移动端明确拒绝并保留项目，非几何断点样式仍写入当前断点。flow/flex/grid、任意变换及第三方CSS结构映射继续列为未完成，不偷偷转换定位。

后续已补原生流式组：连续流式/Flex/Grid兄弟由display:contents容器组织，成员继续参与原父级的排版，不改尺寸、布局和响应式属性。图层显示组，预览显示成员轮廓；拖动成员区域可整组重排，一次命令一次撤销。支持当前移动端分组/解组，几何仍由原布局管理；组框尺寸/背景入口禁用，须编辑成员。锁定后代也禁用组编辑。解组保留子节点全部属性；组样式装饰不能无损摊平时拒绝。外部CSS、table/list等不适合插入div的父级、混合定位或断点切换成定位的成员明确拒绝。
