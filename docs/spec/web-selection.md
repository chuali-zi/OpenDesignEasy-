# Web 多选、批量样式与定位对齐

2026-10-13，R4 的编辑能力切片。沿现有原生WebDocument、Pi上下文和统一命令/历史实现；不改变源码导入/导出功能。

## 用户路径

在预览或图层中普通点选一个对象，用Ctrl/⌘点选添加或移除其他对象。画布Shift同样切换选择；图层Shift根据上次普通/修饰点选的锚点选中连续树范围。图层和画布同步显示全部选中对象，Agent面板同步对象列表。切换页面/文档清空跨页选择；远端删除对象会移除无效选中项。选择属于客户端视图状态，不增加文档修订。

开启“框选”后，在预览拖出矩形选中完整包含的对象；只选择包含子树的最外层，修饰键可追加，未命中时清空。键盘上/下、Home/End浏览图层，Shift扩展范围；Ctrl/⌘+A选择页面对象，Escape清空/退出框选，Ctrl/⌘+D复制，Delete/Backspace删除。文案、源码和属性输入框保留自己的键盘行为。

批量复制/删除仅操作最外层子树，父子同时选中不会重复操作。单次命令对应一次历史；页面根、锁定对象/祖先/后代整批拒绝。复制保留富文本、图片引用、受管组件与响应式属性，插在原件之后，重映射内部HTML id和相关标签/链接引用。复制携带原子树属性前置条件，源内容在提交前变更则拒绝旧副本；删除继续使用内核子树冲突保护。

多选面板显示共同值；不相同或未设置的属性显示“混合或未设置”。支持统一文字颜色、背景色、宽度和高度，使用既有WebDraftField的草稿/起始修订与冲突恢复。一批修改只提交一条命令，对应一次撤销/重做，不覆盖其他人工修改。含任意锁定对象/锁定祖先时整批禁用，不默默跳过对象。

当前视口对应的断点已启用时，批量样式只写入该断点；不存在覆盖时须先创建覆盖。基础样式保留。普通点选返回单对象操作，原有属性、拖动/缩放、源码与历史功能保留。

## 有界对齐支持

支持左/水平居中/右、顶/垂直居中/底对齐，以及三个以上对象的水平/垂直等间距分布。使用真实预览DOM在同一定位容器内的局部border-box坐标，扣除margin后写入left/top；不改变width/height或layout模式，每批一个历史操作。相应right/bottom约束被清除，以避免反向锚点抵消新位置。

本切片限同父级、同offsetParent、可见/未锁定、绝对定位、left/top/width/height为明确像素值的对象，且没有旋转、缩放、translate/transform或其他CSS几何规则覆盖。百分比/auto坐标或尺寸、混合父级、相对/fixed定位及流式对象会明确拒绝，文档不变，不把flow/flex/grid对象转成绝对定位。

预览必须加载相同页面与修订才可测量。提交带选中对象及祖先的样式/布局/响应式/父关系依赖，以及sourceModules/breakpoints前置条件；测量后若尺寸、父级布局、样式模块等变更，整批拒绝。无关的文档名称修改可合并。防止只守护目标left/top而忽略布局测量依赖。
