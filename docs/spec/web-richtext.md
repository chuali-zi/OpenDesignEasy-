# Web 富文本与草稿恢复

2026-10-13，Web 文字使用已有 ProseMirror schema 与 `text.apply` 命令，保存在 WebNode.content；旧纯文本按需转换，text 同步为纯文本投影。支持原生文字容器的双击/属性入口、选区加粗/斜体/下划线/删除线、字体/字号/颜色及段落属性。组件绑定和 select 等非文字容器不开放此入口。

编辑通过同一文档历史提交，撤销/重做、重开、HTML/React 生产与 OEY 源码往返保留格式。源码只使用内部校验和转义后的字面量标记；危险链接降为 #，原生链接/按钮内部的富文本链接只显示样式，避免嵌套交互标签。字体和颜色拒绝 CSS 注入值。

每次文字变更保存浏览器草稿。失败或冲突保留完整格式，并提供明确的恢复/丢弃选择；恢复替换当前元素文字，不静默覆盖远端内容。已提交的相同内容不重复恢复。切换文档时，关闭编辑器的最后一次提交仍指向原文档，迟到结果不替换当前视图。存储失败显示提示；草稿不构成另一个项目真源。
