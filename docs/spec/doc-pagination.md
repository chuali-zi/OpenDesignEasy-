# R5 分页控制、预览与本地原生 PDF

2026-10-13。正文的「段前分页」「与下段同页」「段内不分页」「孤行控制」通过同一 ProseMirror 命令修改，进入人工/agent 共同历史。显式分页符、章节页面参数和这些段落属性生成对应 OOXML；HTML 增补相应分页 CSS、列宽与重复表头。

「分页预览」生成已保存修订的 PDF，显示实际渲染引擎和修订。正文继续编辑后提示预览过时；用户点「更新分页预览」才再生成，没有每次键入自动启动本地 Office。旧修订请求返回 409；同一次请求使用不可变快照。预览验证 PDF 字节与大小，切换/关闭会取消请求并释放 Blob URL，不能把空 PDF 或旧预览报为当前文档。后续普通 nextPage 章节已加入 [分页直接编辑](doc-paged-editing.md)，正文流仍可切换。分开的 PDF 预览不替代编辑能力或 Word 实际验收。

默认 PDF 保留既有 Chromium 路径，预览明确提示其页眉页脚和 Word 排版需要复核。显式设置 `OEY_DOCX_RENDERER=/absolute/path/to/soffice` 时，Web、CLI、Pi 的 Doc PDF 共用当前快照生成的 DOCX，再由本地 LibreOffice 原生分页；结果通过 Web header/CLI JSON/Pi artifact 元数据标明 `libreoffice`。配置后失败直接返回具体原因，不偷偷改回浏览器排版。

原生进程无 shell、无外部链接/模板下载；只传递语言/字体/本地运行所需环境名，不传 provider 凭据。每次使用独立临时目录与 Office profile，最多 45 秒，输入/输出各 25 MiB，0 retry；取消等待退出并清理工作目录，Linux 杀掉整组子进程。Windows 进程树、安装和字体分发仍须 R7 实测，不以此 Linux 验收代替。

## 实测

实际 LibreOfficeDev 26.8 alpha 导出合成 60 行跨页表格，重复表头/页眉和 PAGE/NUMPAGES 字段可抽取核对；中文标题、最后一行和横向附录页尺寸均通过。编译 CLI 在独立合成项目中导出混排报告：原始模板逐字节保存，蓝色标题/3、4 编号/表格边框/原始绿色图片/旋转中文文字框保留，4 页 PDF，最后值 177 可核对。DOCX/PDF/截图、原生页面截图、可复现生成脚本和 JSON 位于 `oey-cloud-evidence/r5-pagination`。

取消试验使用实际独立子进程，300ms 后退出，PID 已不存在；本地 renderer 未收到 provider key。浏览器验证段落分页共享撤销/重做、预览修订、修改后的过时提示、显式刷新及关闭；浮动对象另补 none 环绕的段落顶部/正文栏坐标，避免行内基线偏移。首次 DOM 属性修改造成 ProseMirror 重读循环，已改为 schema 的样式投影，并以真实浏览器回归修复；原失败日志保留。
