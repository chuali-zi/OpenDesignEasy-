# R5 分页直接编辑与支持边界

2026-10-13。普通 nextPage 章节新增真正的分页直接编辑，默认启用。一个 ProseMirror EditorView 持续承载同一正文、光标与选区；浏览器按纸张正文高度将段落、列表、矩形表格、行内图片分到横向连续纸页。页框、页眉页脚、页码与分页测量是视图投影，没有拆成多份文档，也不写入 page 节点或另一套设计状态。跨页文字选择、键盘修改和中文 IME 继续走同一 doc.text.apply。

纸页尺寸、正文高度与纸页间距来自 96 px/in 逻辑单位和当前章节页边距；改变内容、页面或字体后重新分页。分页符、段前分页、与下段同页、段内不分页及孤行控制进入共同历史，页面数量本身不进入历史。视口缩放、横向滚动和切换正文流不改文档。未选章节用相同 schema 与浏览器布局做只读测量，按内容/纸张/章节样式缓存，形成全书页码与页数字段；章节重排后页码随顺序更新。

在纸页页眉或页脚处点击进入该章节的对应可编辑内容，修改后各页显示同一已保存内容。默认页眉页脚的导入沿用原 importer：Word 的关联部件解析为各节明确内容；没有添加隐含的新章节继承规则。章节样式供正文继承，页眉页脚使用自己的默认样式。样式变化重建视图时保留选区；若中文组合输入尚在进行，等组合提交后才切换 schema，不能提前提交半段输入。

行内图片可以在属性面板修改尺寸和说明，浮动图片/形状/文字框继续可移动、旋转、缩放及锁定。浮动 x 坐标相对所属纸页正文栏，段落跨到后一页时补偿栏的实际位置；原图字节不改。保存重开、撤销重做、导出与可编辑再导入仍共享稳定 IDs、模型、资料与版本。

## 边界与原生复核

横向纸页是可编辑正文的实际浏览器分片，不是 PDF 截图覆盖层，也没有将编辑布局写成 Word 多栏正文。正常 nextPage 章节的浏览器分页、全书字段与共享历史为本轮验收范围；连续/奇偶页规则的文档明确显示正文流编辑及原生预览提示，不伪造其页码。可编辑模板不接受多栏或自定义列宽正文，原件保留；其余模板导入范围见 [模板](doc-templates.md)。

每节展示最多 200 张纸页并明确提示超限，计数保留真实页数、正文不截断。矩形表格可以跨纸页继续编辑；编辑视图保留真实首行，不复制可编辑表头节点。原生 DOCX/PDF 通过 tblHeader 重复表头；浏览器编辑分页与 Office 字体/行距/原有 docGrid 的最终分页不保证像素一致。首偶页专用页眉页脚、合并格/嵌套表、复杂域与其他 Word 锚点/环绕仍是明确不支持范围。

Microsoft Word 本机未验，LibreOffice 原生 PDF 保持独立验证；它不是分页编辑的通过依据。新审美反馈未收到，未宣称通过，也未宣称完整 Office 或 D 路线完成。

## 实测与恢复

真实 Blink 组合输入发生在长段落的第二页，组合持续超过保存延迟仍没有提交，确认后仅一次保存；跨页范围删除使页数减少，撤销/重做恢复内容与页数。跨页表格改单元格后保留 18 行，图片修改宽度/撤销/重做后原件字节一致，后一页的浮动对象修改 x 后保存，纸张变化重新分页，重开状态相同。导出的 DOCX 重新导入仍能编辑，原文档未覆盖；原生 PDF 和真实截图另存。

章节页码、重排、点击纸页页脚修改、视口不进入历史、连续规则提示都有真实浏览器验证。另以本地共享命令模拟 agent 改样式：中文 preedit 在源模型中不提前保存，组合提交后新字体生效，保存与 schema 切换之后焦点仍在正文、光标位于已提交文字末尾，可以继续输入；分别撤销两次文字仍保留独立的样式修改。焦点恢复等到新快照被接收且编辑重新启用，不抢走用户已移到其他控件的焦点。没有调用模型 API。
