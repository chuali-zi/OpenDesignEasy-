# R5 Doc 核心编辑与原生生产首个切片

2026-10-13，R4 支持范围内逻辑验收后进入实际 Doc 产品实现。R5 仍在进行，本文不将核心切片当作完整模板/分页/资料接入通过。

## 已实现用户路径

Web 工具栏「＋ Doc」，章节侧栏、正文/页眉/页脚编辑区、A4 横纵向与四边页边距、正文流视图缩放、字体/字号/颜色/选区格式/段落参数、标题/列表、原生 3×3 表格单元格直接编辑、PNG/JPEG 行内图片、显式分页符。所有内容经共享命令进入 SQLite 修订/历史、版本和保存重开；CLI `document create --kind doc`、`document apply/read/render/export` 不要求 Web 服务。Pi 的 project/document 查询、Doc 操作 schema、提交、预览和导出使用同一文档；此次只做离线 faux 验证，没有新增 live 模型请求或费用授权。

章节中的 ProseMirror JSON 是真源，`document.content` 是只读正文投影，内核验证两者一致。章节、块、列表结构、表格行/格与图像保留稳定 ID；新结构分配 ID。操作涵盖 `doc.text.apply`、章节插入/修改/重排/删除、页参数、样式与资产注册。不同章节和无关页参数可重放，同一章节同一正文版本的陈旧步骤拒绝并保留草稿。正文/页眉/页脚独立检查；当前采用保守的同部位文字冲突拒绝，不声称 CRDT 位置映射。

长度统一为 96 px/in，UI 页边距用 mm；DOCX 为 px×15 twips，字号为 px×1.5 half-point。节点/层次、章节、步数与文档大小受限；错误命令不提交部分状态，最后一个章节不能删除，页边距不能消除正文空间。

## 生产与真实验证

固定 `docx` 9.10.0（[官方文档](https://docx.js.org/)）生成原生 DOCX 文字/段落/标题/列表/表格/行内图片/节/样式/页眉页脚；图片包内字节与原件一致。每节显式写入空或有内容的页眉/页脚，避免 Word 自动继承上一节使导出偏离模型。CJK 字体使用 Noto Sans CJK SC；目标机器的字体兼容性仍需复验。非支持色值及 WebP 原件转 DOCX 显式拒绝，不降级或丢弃原件。HTML/PDF/PNG 通过同一结构派生，Chromium 过程禁止外部网络并接受 abort。

实际合成报告含 60 条数据、跨页表格、第三项起始的有序列表、中文、原生 PNG、页眉页脚和横向附录。LibreOfficeDev 26.8.0.0.alpha0 真实打开 DOCX 并转换 4 页 PDF：前三页重复表头/页眉页脚、最后横向节不错误继承；中文和最后一行 177 均可提取。首次发现测试 PNG 的 IDAT CRC 不合法，修正新 Doc 合成夹具；随后原生应用不再报告解码错误。这是 LibreOffice 验证，不是实际 Microsoft Word 通过。

Node 全套 132/132、Chromium 全套 24/24、核心与 Web 构建通过；修正显式空页眉/字体后再跑 Doc 核心 2/2，并再次通过全量 Node 132/132、Chromium 24/24 及构建。浏览器贯穿创建→正文/表格/图片→章节/页边距/页眉→撤销重做→保存重开→DOCX/PDF；离线 Pi 10/10 中包含 Doc 工具共享历史和原生导出场景。

首轮浏览器读到了旧 production dist，先构建后复测；第二轮 selector 把 ProseMirror 的光标辅助 IMG 当成真实资产，改以 `data-asset-id` 定位真实图片，仍断言恰好一张图片并检查持久内容。未删除内容或历史断言。

## 仍须完成的 R5 范围

- DOCX 模板结构导入、支持范围内 OOXML 保留/修改与样式继承；未知结构保留原件并说明具体拒绝范围。
- 浮动图片/图形、锚点与正文重排/尺寸/旋转等混排交互；表格行列结构编辑和更完整复制操作。
- 真正的分页编辑预览、跨页表格及页眉页脚对应生产差异。当前编辑器正文流延展；Chromium PDF 的页眉页脚暂在正文流中，不能声称重复页眉与 Word 一致。
- PDF/扫描 OCR、PPTX/DOCX、XLSX/CSV、图片和源码的 TS 资料读取及可编辑导入。
- 实际 Microsoft Word 打开、字体/锚点/排版复验与正式模板/教学资料任务。当前容器只有 LibreOffice，不能代称 Word。
- 新 Doc 面板已保留合成真实截图，审美待用户判断；不代替用户作审美通过结论。

可复现证据在独立 `oey-cloud-evidence/r5-doc-core`，代码经独立分支正常推送；没有改主分支、merge/force push，也没有创建代码 ZIP。产品 Web source.zip 继续保留。
