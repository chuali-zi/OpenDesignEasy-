# R5 DOCX 模板结构导入与 OOXML 往返

2026-10-13。Web「导入 DOCX」、CLI `document import-docx <dir> <template.docx>` 创建新的可编辑 Doc，不覆盖当前文档。原始 DOCX 作为不可变资料完整保存，界面可下载原始模板；图片原件独立保存并在同一事务中注册。

支持正文段落/标题、已解析的字体/字号/颜色/粗斜划线与 basedOn 样式继承、平面有序/无序列表、矩形表格与列宽、章节/纸张/页边距、默认页眉/页脚、普通行内 PNG/JPEG、分页及 PAGE/NUMPAGES 字段。显式 false 样式覆盖继承的 true；初版不声称任意 Office 文件无损编辑。

复杂字段、样式定义编号、合并格/嵌套表、首/偶数页专用页眉页脚、浮动或裁切/变换图片等当前无法可靠映射的结构明确拒绝。宏/ActiveX/OLE、活动模板关系、外部非超链接资源、XML entity、损坏 ZIP/PNG 拒绝，不执行源码/宏或下载资源。关系类型与资产路径经过受限 ZIP/XML 读取检查。原文件和原文档在拒绝时保留，失败不创建部分文档/资产。

导入最多 8 MiB，继承 Office ZIP 的条目/解压上限与 XML 深度限制；文档模型最多 4 MiB。重复 commandId 的相同请求复用文档，不同输入冲突。并发重复在提交前再次检查并清理本次暂存文件；所有原件/图片记录、文档、事件与幂等结果一起提交。

## 真源、原件与格式保留

ProseMirror 结构、稳定 ID、样式/章节/页参数仍由 Doc 命令修改，人工与 agent 共用历史。templateSource 仅记录不可变原件校验和、对应 XML 位置与基准属性，不另开文件写入旁路。导入的 ooxmlRun 标记保留原始字符属性来源；编辑步骤保留这些标记，仍可正常修改文字和已支持格式。

未编辑或撤销到导入状态时，语义指纹匹配后逐字节导出原 DOCX。编辑后重新生产可编辑正文，将未改的字符/段落/表格/节属性、原始样式 XML 与额外包部件保留；已改的模型属性覆盖对应属性。重新绑定图片关系与默认页眉页脚引用。列表使用重新生成的序列身份，保留相应原始编号定义属性。原件校验和不符时停止导出，不自动修复或覆盖它。

OOXML 的属性顺序影响实际应用。在首次真实 LibreOffice 打开时，发现属性虽存在但被移到内容后，导致标题、编号、边框被忽略；已修复 pPr/rPr/tblPr/trPr/tcPr 的结构位置，保持表格网格与节引用顺序，并补结构顺序回归。再次实际打开确认蓝色标题、3/4 编号、表格边框、绿色原图恢复，中文修改与最后一行 177、横向附录均可核对。失败的原生 DOCX/PDF 与最终结果都保存在独立证据目录，未把仅 XML 字符串通过冒充格式通过。
